# content-db — Content Idea Database (BONES)

Where ideas live between sessions so Brent can batch + schedule once a week.

> **Status: BONES.** Format/location not finalized. Candidate: flat markdown here,
> or sync with `vault-personal`. Decide when fleshing out (task #6).

## Proposed idea schema (draft)

Each idea = one entry:

- **id** — short slug
- **hook** — one-line angle (the pattern interrupt)
- **pillar** — AI-automation / The-Third-Window / Rebuild-systems
- **audience layer** — young hustler / experienced operator / late-innings rebuilder
- **source/receipt** — link or local file (screenshot, metric, story)
- **status** — idea → drafted → reviewed → scheduled → posted
- **platforms** — FB / IG / YouTube / X

## Weekly rhythm (target)
Capture ideas all week → one batch session → `write-content` drafts → review →
`blotato-post` visuals + schedule. ~1 hour, Sabrina-style.
