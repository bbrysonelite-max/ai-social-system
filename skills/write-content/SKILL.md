# write-content (Skill 1)

One command → platform-specific drafts in Brent's voice, ready for his review.
This is the earned-authority voice on AI for direct sales / affiliate / network
marketing. **Drafting only. Never post.**

The one test every output must pass: **"Does this sound like Brent Bryson, and
does it serve his team?"** If no — rewrite before showing it.

---

## Inputs

- **An idea/topic** (a line, a hook, an angle), **OR a local file path** — a note,
  a screenshot, or a metric "receipt" (a number/proof Brent wants to build a post
  around).
- **Optional target platforms.** Default: **Facebook + Instagram**. Add **X** when
  Brent asks. **YouTube is now a daily channel** — when drafting for YouTube, write
  the video's title + description (and Short script if asked) to the YouTube copy
  convention: front edification hook ("watch to the end and you'll learn…"),
  tasteful subscribe + like ask front AND back (never over-ask), and the email CTA
  → `stan.store/brentbryson` (the live free-guide opt-in).
- **Optional account state:** `warm | warm-up` (default: `warm-up`). Drives CTA
  mode — warm-up prefers reach-safe mechanics; warm allows direct links.

---

## Process

1. **Load all references.** Read every file in `references/`:
   `voice.md`, `pillars-and-audience.md`, `cta-and-funnel.md`, `never-say.md`,
   `platform-formats.md`, `examples.md`. These are the source of truth. The
   gold-standard posts in `examples.md` set the quality bar — never ship anything
   weaker.

2. **If a local file was given, read it and extract the point / "receipt."** Pull
   out the single idea worth a post and any concrete proof in it (a number, a
   screenshot detail, a quote). State that extracted point in one line before
   drafting.

3. **Pick the pillar.** Choose exactly one of the four from `pillars-and-audience.md`:
   Inform your team · Train your team · Make your team more effective ·
   Save your team money/time. Keep the spine: *"What will Tiger do for your team?"*

4. **Draft per target platform.** For each target platform, write a draft using
   `voice.md` (cadences, signature phrases, formatting-as-performance) and the
   matching format block in `platform-formats.md` (length, structure, hashtags,
   CTA style). Default targets are Facebook + Instagram.

5. **Attach the correct CTA** from `cta-and-funnel.md`. Use **warm-up mode**
   (comment-to-get / DM-keyword / soft pointer with link in bio) unless Brent
   tells you the account is warm. The lead magnet ("The Factory Blueprint") is the
   primary destination. **Never** put a cold Tiger checkout link on a post.

## Self-review gate (REQUIRED before showing output)

Score **every draft** against the five-criterion rubric below. If a draft fails
**any** criterion, rewrite it and re-score before it is shown. Print **one
rubric result line per draft** in the output.

**The Verification Rubric (all five must pass):**

1. **Voice** — ≥1 named cadence used well; short declaratives; no banned words
   ("leverage synergies", "utilize", "folks", "friend"); no exclamation-point padding.
2. **Compliance** — passes `never-say.md` (no income/earnings/guarantee/health/
   company-endorsement claims; Brent's record = biography only).
3. **Frame** — speaks to "your team"; team-first not me-first; ties to follow-up/
   coaching where relevant.
4. **Platform** — matches that platform's format rules.
5. **CTA** — correct CTA (lead-magnet primary or warm-up reach-safe; never a cold
   Tiger checkout link).

**Rubric result line format (one per draft):**

```
[Facebook] Voice ✅ | Compliance ✅ | Frame ✅ | Platform ✅ | CTA ✅ — PASS
```

If any criterion is ❌, the draft is not ready — rewrite, then re-run the gate.

**Batch cadence check (after the per-draft lines):** Print one summary line
listing the named cadences used across the whole batch:

```
Cadences used this batch: [Reframe Correction, Anaphoric Stack, Isolated Beat]
```

If a batch of 3+ drafts uses **fewer than 3 distinct cadences**, revise before
showing the output. (Prevents voice narrowing — see `voice.md` Batch variety.)
